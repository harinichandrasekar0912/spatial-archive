# Spatial Archive

A lightweight Vite-based front-end experience for presenting a spatial archive of projects.

## Project structure

- `src/app` contains application composition and shared state.
- `src/ui` contains page and component markup.
- `src/three` contains scene and visual system utilities.
- `src/data` contains project content.
- `src/utils` contains animation and accessibility helpers.

## Scripts

```bash
npm install
npm run dev
npm run build
```
